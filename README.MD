Клеточное поле размера N (можно задать, но всегда нечетно).

По началу игры на поле 1 клетка в самом центре (это остров, им можно управлять - пока стрелочками,).
С разных сторон в противоположенную могут появлятьсяя и лететь фигуры. При столкновении с островом они прикрепляются к нему.

Относительно базовой клетки, каждый слой, если он полностью заполнен, исчезает, при этом (пока сделаем так, все остальные клетки отваливаются до этого уровня, каждая клетка в исчезаемом слое дает +5 очков, каждая которая отвалилась +1).

Если остров коснулся любой своей клеткой любой стены, то игра окончена.

Игра по умолчанию с таймером, и дается 60 секунд. При схлопавании слоя, таймер добавлет еще 60 секунд.
Добавить отдельно действие на кнопку, для ускорения полета новой фигуры. (Фигуры сделать базовые из тетриса, летят в рандомном порядке, с любой части экрана, но не стой же стороны, с которой было в прошлом полете).

Остров можно поворачивать на 90 градосов по и против часовой стрелке - добвить по клавишам.

Цель - держаться как можно дольше и набирать очки на рекорд.
